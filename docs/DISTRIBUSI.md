# 📤 Distribusi Kasir Pro ke Banyak Perangkat

Panduan singkat untuk membagikan aplikasi **Kasir Pro (APK)** ke semua
perangkat kasir/HP tim. Paling praktis: **Google Drive + tautan berbagi**.

---

## 1. Rekomendasi: Google Drive / Dropbox

- **1× unggah → 1 tautan → kirim ke semua perangkat sekaligus.**
- File sama bisa dipakai berulang kali + perangkat di mana pun (tanpa USB/kabel).
- Update sekali → semua dapat versi baru dari tautan yang sama.

---

## 2. Cara Unggah (dari komputer)

1. Ambil file **`KasirPro-v1.0.0.apk`**:
   - Buka panel **Explorer** → folder `dist/`
   - Klik kanan `KasirPro-v1.0.0.apk` → **Download**
2. Buka **drive.google.com** → tombol **+ Baru** → **Upload file**
3. Pilih file APK → tunggu selesai.
4. **Klik kanan file** → **Bagikan** → atur **"Siapa pun yang memiliki tautan"**
   → salin tautan (link).
5. Kirim tautan ke semua kasir via WhatsApp/grup/email.

> 💡 Gunakan **satu folder** (mis. `Kasir Pro`) agar semua file pendukung
> (APK, struk contoh, panduan) dalam satu tautan folder.

---

## 3. Instalasi di Perangkat Kasir (Android)

1. Buka **tautan Drive** di HP kasir → unduh APK.
2. Buka file APK (dari notifikasi unduhan / File Manager).
3. Android akan menolak pertama kali → muncul peringatan **"Instal dari sumber
   tidak dikenal"** → ketuk **Pengaturan** → **Izinkan dari aplikasi ini**
   (atau: Pengaturan → Keamanan → aktifkan *Install unknown apps* untuk Chrome/Drive).
4. Ketuk **Instal** → **Selesai**.
5. Buka **Kasir Pro** → login `admin/admin123` atau `owner/owner123`.

---

## 4. Tips Memperbarui ke Semua Perangkat

- **Jangan ganti nama file** (`KasirPro-v1.0.0.apk`) — tautan tetap valid.
- Saat rilis versi baru: **unggah APK baru dengan nama sama** → semua perangkat
  tinggal buka tautan yang sama, unduh, & **Instal (update)** — data tetap ada
  (tidak perlu uninstall).
- APK rilis update-able selama **appId sama** (`com.kasirpro.pos`) — sudah
  dijamin di build.
